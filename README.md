# Практика с ООП
В этой работе было выполнено задание по теме разработки используя ООП-подход для создания своих сервисов, а также использование инициализации и методов ООП для создания распределения классов на продукты и категории.

##Наследование
Было добавлены нововведения: 2 новых класса смартфоны и трава газонная; основанные на наследовании старых функций. Также была проведена работа над улучшением старых алгоритмов, добавлением возможностью использования обьектов только из соответствующих категорий.
